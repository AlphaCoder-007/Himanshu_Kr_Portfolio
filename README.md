## Tech Stack

- **Frontend:** React.js, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Node.js, .NET Core, REST APIs
- **Database:** SQL Server, MySQL, MongoDB
- **Testing:** Selenium WebDriver, Playwright, Postman
- **DevOps:** Git, GitHub Actions CI/CD, Azure

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Run tests
npm test

# Lint
npm run lint
```

## Deployment

Pushes to `main` automatically deploy via [GitHub Actions](.github/workflows/deploy.yml).
